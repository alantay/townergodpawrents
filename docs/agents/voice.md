# House voice

Read this before writing any words that show up on the site: diary entries, dog taglines, page copy, labels, error messages, meta descriptions.

The voice is Alan's. Personal, warm, a bit dry. Like telling a neighbour what the dog did today.

## Hard rules

- Go light on Singlish. Alan's own words, such as "manja", are fine. Never "lah", "leh", "lor", "sia" or similar particles. Don't add Singlish to sound local. Prefer "chilling" over "lepak".
- No em dashes or en dashes as sentence punctuation. Use a full stop or comma. Use en dashes for ranges: "13–23 Sep", "30 Sep – 13 Oct", "9–11am".
- This is a personal site. No marketing copy, calls to action, pricing, service descriptions, testimonials or FAQs.

## Style

- Keep sentences short and wording plain. Prefer "No dog today" over "No doggo" or "Vacancy".
- Use deadpan understatement ("House intact."), the dog's point of view ("Burdensome, Tiny says."), or a mix-up. Avoid forced jokes, stacked puns and excessive exclamation marks.
- Let the action set up the joke, then give it a short closing beat: "Luna came charging in, cute skirt and all, and went straight for the blue squirrel plushies. So unladylike."
- References should work without explanation. Alan's "Lord Tyrion" and "Lady Luna" titles work without knowing Game of Thrones.
- Headings, badges and sublines should add something to each other. Avoid repeating the same words or idea.

## Diary entries

- Keep the dog the main character. Name the humans when describing events: "Alan got home." "Tiny eyed Weiwen's toast."
- Use "we / us / our" when both humans did it together: "We took Tiny to Kallang."
- "I" is fine for personal reactions: "I swear…", "I melted". Don't turn these into "Alan swears…" or mix "I" and a human's name in one sentence.
- Use past tense for events ("Tiny finally pooped"). A present participle is fine for captions ("Tiny napping on the lap while the human tries to work").

## Keeping this guide useful

These rules apply to new writing. Published diary entries stay as they are.

When Alan reacts to wording, add a general preference here only if it will help with future writing. Keep examples few. Record one-off choices in [voice-history.md](voice-history.md); consult it when revisiting that copy.
