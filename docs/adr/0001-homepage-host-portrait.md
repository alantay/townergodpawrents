# ADR 0001: Homepage host portrait

## Decision

Show Alan and Weiwen in the home-page host card as a warm, hand-cut editorial portrait. The portrait uses the rice-field selfie as its identity reference, retains their recognisable faces and glasses, and uses a cream, green, and lime paper-collage treatment.

## Context

The host card is only 134 by 154 pixels at its intended display size. A close, face-forward portrait reads more clearly than a detailed travel photograph and better matches the site's playful, personal visual language.

## Consequences

The page uses `public/images/alan-weiwen-portrait.png`. The original source photos stay outside the project and are not published.
